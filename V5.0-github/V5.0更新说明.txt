命运之书 V5.0

基于 v4.4 最新工作副本修复升级。

主要更新：
1. 文风功能接入玩家选择方向，在 AI 判断剧情前注入叙事模式和细节限制。
2. 支持战斗、探索、社交、休息、修炼、任务、悬疑、危机、逃离等行动类型。
3. 文风记忆进入存档，读取存档后恢复。
4. 伏笔生成完成不再依赖新人物分支。
5. 伏笔进入 GameEngine.state.foreshadows 并随存档保存。
6. 支持 Markdown 伏笔格式，包括 **伏笔埋设**：内容。
7. 已通过模拟完整闭环和一次真实 DeepSeek 生成测试。

原有版本未修改。

API 配置修复：
- DeepSeek 地址仅作为默认值，不再强制写死。
- 用户填写的任意 OpenAI-compatible Chat Completions 地址会原样保存并使用。
- 用户填写的模型 ID 会由服务端统一应用到剧情、文风学习和 AI 助手请求。
- 已验证自定义地址/模型保存、读取与重启恢复。
